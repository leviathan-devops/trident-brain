# TRIDENT BRAIN

Multi-mode algorithmic code review system for OpenCode.

---

## MODES

### Code Review Mode v3.2

Self-contained code review plugin with automatic artifact generation.

**Location:** `code-review-mode/v3.2/`

```bash
# Quick Deploy
cd code-review-mode/v3.2
./scripts/deploy.sh

# Or manual:
bun build src/index.ts --outdir dist --target bun --format esm --bundle
cp dist/* ~/.config/opencode/plugins/trident-brain/
```

### Available Tools

| Tool | Description |
|------|-------------|
| `trident-audit [target]` | Run code audit, generates TRIDENT_CODE_REVIEW_*.md artifact |
| `trident-status` | Show current audit state and findings |
| `trident-report` | Show full detailed findings report |
| `trident-help` | Show available commands |

### Core Principle

> **"Trident Documents. Humans Fix."**

TRIDENT NEVER edits code or applies fixes. It only documents findings with:
- **WHY** — Mechanistic explanation of why each issue is problematic
- **HOW** — Step-by-step fix instructions for human review
- **Verification** — Mechanical proof commands to verify fixes

### Artifact Output

When `trident-audit` completes, it generates:
- `TRIDENT_CODE_REVIEW_{context}_{date}.md` in the target directory
- 3-layer WHY/HOW structure
- Critical path with fix order
- Raw findings table
